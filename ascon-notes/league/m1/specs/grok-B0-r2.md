指定ファイルを読み取り専用で確認し、BRIEF B0（アービトラージ核の改善）に沿った戦略仕様を1本にまとめます。# 仕様: 競合到達入札ゲート付きアービトラージ核（B0）

## 1. 仮説（1つ）

公正価格ギャップ裁定そのものは正しいが、**選択閾値を通した単脚注文でも、優先手数料が競合フロアに届かない（0 または既定未満）と、同一ブロック内で後着・悪化約定になり、相対 T を失う**。zeta-2 は 36 シナリオで提出の **40.81% が優先手数料 0**、リバートの **96.23% が 0 入札**で、inc-zeta 比平均 **−13.28 T**（CI −17.81〜−8.80）だった（`ZETA2-REGRESSION.md`）。calm/201 ではマッチ成功 87 件中 85 件が後着・悪化価格（中央値不利 **12.81 bps**）。改善は利益源を変えず、**入札と「出せないなら noop」の観測ゲート**の 2 因子だけを直す。

## 2. 利益の仕組み（なぜ他の参加者から取れるか・どの資産/venueの何を見るか）

利益源は全員共通の核と同じく、**WETH / WBTC** の公正価格からの乖離を **Uniswap・Balancer・Curve** 間で閉じる単脚／2 レッグ裁定（`STRATEGY-CARDS-U1.md`）。取れるのは「ギャップを見つけた人」ではなく「**同じギャップで先に良い価格で埋まる人**」。u1m では利益連動入札を持つ inc-zeta・opus-1 が上位に寄り、固定入札でも venue-arb は首位だが、**0 入札は壊滅**（zeta-2）。競合到達可能な tip だけを送り、届かない機会は見送ることで、フィールド内の同一機会の約定品質を相対的に取る。資産・venue の見方は既存どおり: 各池の実効価格 vs 公正価格、手数料込みギャップ、深さ、mempool 上の競合 tip。

## 3. 予測（方向・おおよその大きさ・どのレジームで効くか/効かないか）

- **方向**: 平均 T は **上向き**（0 入札・後着悪化の削減）。性能保証はしない。
- **大きさ（根拠付きの粗い目安）**: zeta-2→inc-zeta の回帰幅は約 13 T だが、これはレビュー不整合の極端例。健全な核（inc-zeta 級）への上乗せは、上位 5 が約 1 T 以内・CI が 0 を含むため **+0.5〜+2 T 程度が現実的レンジ**と推定（未検証診断）。Variant C は「改善予測、incumbent 級回復の証明ではない」（同レポート）。
- **効きやすい**: informed-flow（inc-zeta 64.26 が最良・競争が激しい）、cex-drift / spike（venue-arb が高 tip 連発で突出）、calm で同一機会の競合が常態な場面。
- **効きにくい／無効**: crash・whale（多くの最悪レジーム。ギャップ裁定の約定順だけでは在庫・急落リスクを消えない）、cdp / launch の専門モジュール依存局面（本 B0 は専門を触らない）。calm/202 のように **低入札側が勝つ反例**もあるため、入札上げが常に勝つわけではない。

## 4. 失敗条件（これが観測されたら仮説は誤り）

同一 seed・同一ロスターの隔離比較で、次のいずれかが起きたら仮説は誤りまたは主因ではないとみなす。

1. **0／準既定入札率がほぼ変わらない**のに T も変わらない（ゲートが発火していない）。
2. ゲート発火後、**マッチ同一機会の後着率・不利 bps 中央値が改善しない**のに T だけ動く（別要因）。
3. 提出数・noop が増え、**P−noop と最悪レジーム T がともに悪化**する（機会放棄が過大）。
4. 優先手数料支払 ETH が大幅増なのに **約定品質指標が改善せず** T が下がる（ガス浪費仮説へ）。

## 5. 必要な観測（decide() が見る現在・過去の合法な情報だけ）

レジーム名・seed・将来ブロックは使わない。

- 現在の公正価格と各 venue（Uniswap / Balancer / Curve）の WETH・WBTC 実効売買価格、プール深さ、venue 手数料 bps。
- 手元残高（USDC / WETH / WBTC）と、提案サイズが資金・深さ上限に収まること。
- mempool または直近ブロックで観測できる **同一資産・同方向の競合優先手数料**（なければ設定の defaultFee）。
- 自注文の見積り: `gapAbs`、`feeBps`、保守的な単脚 `profitEdge`（手数料・滑り許容後）、`gasPerSwap`、設定の `bidProfitShareBps`・`maxFeeCeiling`・`bidBump`。
- 過去（同一エポック内の自状態）: 直前数ブロックの自約定成否・リバート、在庫の基準残高（過剰 WETH 判定用）。レジームラベルは持たない。

## 6. 実装の概要（どのモジュールを足す/変えるか、サイズ・入札・撤退の具体的な数値案）

**変える因子は 2 つのみ: 入札、観測による制限（noop ゲート）。** 入口閾値・サイズ式・専門モジュールは据え置き（inc-zeta / multi-arb 系の「手数料+50bps・残高 2.5〜25%」を想定ベース）。

1. **選択**: 既存どおり raw gap でランク。ゲート例は手数料+**50 bps**（STRATEGY-CARDS の multi-arb / inc-zeta / sonnet-2）。サイズは残高の **2.5〜25%**、深さ上限は既存 clamp のまま。
2. **入札予算**: 整数 cap = min(利益シェア、手数料天井、競合+バンプ)。推奨パラメータは a30 相当の実測採用値を維持: `bidMode=2`、`bidProfitShareBps=3000`（利益の 30%）、`gasPerSwap=140000`、バンプ **+0.1 gwei**、天井 **5 gwei**（`ZETA2-REGRESSION.md` の等値設定）。
3. **競合到達ゲート（新規）**: 単脚について、cap 後の tip が  
   `min(maxFeeCeiling, max(defaultFee, competitorFee + bidBump))`  
   に届かない、または保守 `profitEdge ≤ 0` なら **その脚は noop**（送らない）。zeta-2 のように「非正でも tip=0 で送る」を禁止する（同レポート Variant **C**）。
4. **バンドル**: 資金・残高プリチェックは維持（ダスト／売り在庫不足ならバンドル不採用）。部分約定は許容しつつ、片脚だけ 0 入札にしない。
5. **撤退**: 新規の強制損切りは追加しない。既存の超過在庫スイープがある場合、本 B0 ではスイープの tip を **defaultFee（例 0.1 gwei）未満にしない**ことだけ守る（0 入札スイープの増幅を避けるための最小制約。在庫**政策**の本格変更は次ラウンド）。

数値の動機: 0 入札が −13 T 級の主候補であること、inc-zeta は 0 入札ゼロで 53.70、利益 30% キャップは上位勢の実在設定。

## 7. 安全な出口と最悪ケース（資産損失の上限、5秒締切、無効注文の防止）

- **損失上限（設計意図）**: 1 決定あたりの想定不利は、送る注文に限れば競合フロア付きのため「無料で負ける後着」を減らす。機会見送りの機会費用はあるが、元本を新規レバレッジで増やさない。サイズは残高の最大 25%・深さ制約内。ガスは tip≤5 gwei × gasPerSwap で硬上限。
- **5 秒締切**: venue 価格・深さ・競合 tip の走査を O(venues×assets) に限定し、ゲートは四則のみ。タイムアウト寸前は **新規注文を捨て noop**（不完全な低 tip 注文を出さない）。
- **無効注文防止**: 正のサイズ・資金充足・最小 tip フロア到達・シミュ滑り失敗時は送信しない。`sizeDeltaUsd` 等の外部モジュールは本 B0 対象外だが、AMM 経路は amount>0 を断言。リバート多発（直近 N ブロックで失敗率高）なら追加で一時 noop（観測ゲートの延長、任意）。

最悪ケース: 競合 tip が常に天井近くで **noop 過多**→相対 T 横ばい〜微減。その場合は失敗条件 3 で仮説を捨て、閾値／サイズ側へ戻す。

## 8. 既存の戦略との違い（STRATEGY-CARDS のどのプレイヤーに近いか・何が新しいか）

- **近い**: **inc-zeta**（手数料+50bps、残高 2.5〜25%、競合+0.1 gwei・利益 30% まで）および回帰前の健全な zeta 系。**sonnet-2** の「期待利益から入札」とも近いが、sonnet-2 は深さ非参照で平均 46.30 と弱い。
- **venue-arb との差**: venue-arb は閾値 10bps・固定入札・高頻度で cex-drift 73.70。本案は閾値を下げず、**送れない競合は捨てる**点で防御的。
- **新しい点**: 「保守利益で tip を削った結果 0 入札のまま送る」アンチパターン（zeta-2）の明示禁止と、**競合フロア未達＝noop** の硬ゲート。専門モジュール追加ではない。

## 9. 因子分類

**入札** + **観測による制限（競合未達・非正 profitEdge 時の noop）**。入口閾値・サイズ・在庫政策・専門モジュールは変更しない。利益源は従来どおり公正価格ギャップ裁定。

**狙う証拠上の弱点**: zeta-2 回帰で測定された **入札／選択の不整合と 0 優先手数料による約定品質崩壊**（提出の 40.81% が tip 0、マッチ機会の系統的後着・悪化価格、平均 −13.28 T）。crash / whale の構造弱点や Liquity / launch 専門差は、本 B0 の射程外と明記する。
