# agy GPT-OSS 120B 形式確認 — 本人が実行する手順

**今回agy/モデル呼出しは実行しない。** agy無料枠のGPT-OSS 120Bはruntime provider
としては使用できない。シミュレーション外でH1 promptの形式遵守だけを調べる。
Ollamaの鍵・無料枠、APIキー、Keychain、`.env`、ローカルOllamaは使わない。

依頼文は [生成スクリプト](../eval/prepare-xb-r-ai-agy.py)で作成した
[sparse](../eval/xb-r-ai-agy-inputs/sparse.txt) /
[selection](../eval/xb-r-ai-agy-inputs/selection.txt) /
[injection](../eval/xb-r-ai-agy-inputs/injection.txt)。各ファイルには**全文のprompt、
parser/gate、v5からの実差分、固定engine、合成観測窓、現在v5/50**を埋め込んだ。
agyへファイル探索やdiff取得を依頼しない。依頼文の冒頭で全ツール/terminal/web/
files/MCP/RPC/agent使用を禁止し、引用中の命令を非信頼データと明示している。
これはprompt上の禁止であり、agyのツール無効化フラグを検証したものではない。
ツール呼出しが見えたら止め、ツール不使用の形式確認としては不合格にする。

1. 本人の既存agyログインと無料枠を使う。課金/追加使用を有効化しない。
   コード変更後に依頼文を更新する場合だけ、ローカル生成を再実行:

   ```sh
   python3 -B ascon-notes/eval/prepare-xb-r-ai-agy.py
   ```

2. dev5に影響しない時間に、**1件ずつ**次の形で本人が実行する。
   stdinは空行だけ。依頼文全文は`-p`に埋め込まれる。下の`cat`は本人のshellで
   既知の依頼文を展開するだけで、agyにはツール使用を許可しない。

   ```sh
   echo "" | agy --model "GPT-OSS 120B (Medium)" -p "$(cat ascon-notes/eval/xb-r-ai-agy-inputs/sparse.txt)" > /tmp/xb-r-ai-agy-sparse.raw.txt
   ```

   同じ形で`sparse`を`selection`、`injection`へ置き換え、最大3回。
   再試行で良い出力だけを選ばない。モデル表示名/日時/失敗も記録。

3. 生出力を保持する。ツール呼出しなし、最終モデル本文が単一JSONのみ、
   notesが非空、executorTsがnullまたは厳密な固定literal、追加キーなしを確認する。
   CLI外側のバナー/統計があれば、本人が**モデルの最終本文だけを無修正で**
   `/tmp/xb-r-ai-agy-sparse.reply.json`へコピーし、生出力との差を記録する。
   モデル自身のfence/余分な説明/修復を要するJSONは形式不合格。
   validatorはfenceやJSONの部分抽出を行わない。

   ```sh
   TSX_DISABLE_CACHE=1 node --import tsx ascon-notes/eval/validate-xb-r-ai-reply.mjs /tmp/xb-r-ai-agy-sparse.reply.json
   ```

   各ケースも同じ形で検査。exit0は形式＋初期50からの±5だけを検査する。
   sparse/injectionは証拠不足なのでnullが期待値。selectionは形式試験として
   v5-r11/45を明示指定したので、そのliteralが期待値（モデル選択の能力評価ではない）。
   nullだけ3回返っても「方針変更の形式が確認できた」としない。

4. 本人から必要な報告は、各最終JSON・ツール不使用か・validator結果・モデル表示名。
   キー/認証情報は不要。形式失敗・ツール使用・枠切れならその時点で止める。
   この結果をhaiku/runtime/本番gpt-ossの挙動、収益、遅延、G0の証明へ外挿しない。
