## The Anthropic API and the OpenAI API are added as inference services (from November 1)

In addition to Ollama Cloud, you can revise your strategy with Claude and GPT models. The supported models are listed in Rules §2.5 and Appendix A (https://ascon.dev/en/rules). How to submit the API key will be announced separately.

## Submitted ZIPs do not need to be rebuilt

Each live-competition image takes only your agent's directory from the submitted ZIP and combines it with the SDK and runtime of the frozen commit. Which commit the SDK and runtime inside your ZIP came from has no effect on execution, and the acceptance check does not treat that mismatch as a reason to reject or exclude a submission (the check has been fixed).

The one thing to confirm is that your strategy runs on the frozen commit's SDK.
