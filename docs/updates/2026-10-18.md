ライブ競技の各エポックの世界（レジームと seed）を抽選する元になる、非公開セットのハッシュを公表します（競技規約 §7.1）。

```
sha256:96eb9ffe903088d11865a49dec1694c81ae237cedf41e929de91d6f02c1d6ddd
```

§7.1 では提出期間の開始までに公表する定めでしたが、遅れました。申し訳ありません。

原本は結果発表の後に公開します（§7.2）。公開されたファイルに `npm run competition -- commit <file>` を実行すると、ファイルを正規化した JSON の SHA-256 として同じ値が出ます。主催者が後からシードを差し替えていないことは、これで確かめられます。

残りの 2 つは次の時期に公表します。

| 対象 | 公表の時期 |
|---|---|
| 非公開セットの生成鍵のハッシュ | 提出期間の終了まで（10/31） |
| エポック順序の抽選用シードのハッシュ | 提出期間の終了時（10/31） |

## 提出 ZIP は作り直す必要がありません

ライブ競技のイメージは、提出 ZIP のうちエージェントのディレクトリだけを取り出し、凍結コミットの SDK と runtime を組み合わせて作ります。ZIP に同梱した SDK と runtime がどのコミットのものかは、実行に影響しません。受付時の検査でも、この不一致を不受理や除外の理由にはしません（検査は修正済みです）。

確認していただきたいのは、凍結コミットの SDK で戦略が動くかどうかだけです。
